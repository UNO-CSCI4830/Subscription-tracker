# SubTracked
**Centralized Subscription Management for the Modern User**

SubTracked is a secure web application built for CSCI 4830: Intro to Software Engineering. It allows users to track recurring expenses, visualize monthly spending, and manage subscription cycles in one centralized dashboard.

---

## Live Demo
**[Access the Live Application Here](https://uno-csci4830.github.io/Subscription-tracker/)**

---

## Key Features
* **User Authentication:** Secure login and registration powered by Supabase.
* **Subscription Management:** Full CRUD (Create, Read, Update, Delete) functionality for subscription records.
* **Dynamic Dashboard:** Real-time calculation of total monthly and annual costs.
* **Guest Mode:** Allows users to test the application using local browser storage without creating an account.
* **Responsive Design:** Fully optimized for desktop and mobile viewing.
* **Automated Logic:** Logic for tracking renewal dates and "days remaining" for each service.

---

## Tech Stack
* **Frontend:** Vanilla JavaScript (ES6+), CSS3, HTML5
* **Backend/Database:** Supabase (PostgreSQL)
* **Authentication:** Supabase Auth
* **Testing:** Jest Framework
* **Deployment:** GitHub Pages
